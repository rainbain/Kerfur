# Kerfur
Kerfur is a open source web based LLM coding agent platform written in Rust.

The goal is to provide a coding agent system that breaks away from the sort of ChatGPT clone style we see
and develop a web platform with project based workflows that helps smaller, easier to self host agents,
handle simple task accross projects. 

It also aims to add a bit more character and create an interface thats more interesting to use. UwU.
